# 同義語

類義語は、検索クエリを展開し、買い物客がカタログ内の単語とは異なる使用する可能性のある単語を含めます。 誰かが「ソファ」を探している間に、製品が「ソファ」としてリストされているので、販売を失いたくありません。 顧客が自社商品を探す際に使用する可能性のあるあらゆる単語を入力して、幅広い検索語を取得します。

このシステムは、デフォルトで[&#x200B; セマンティック検索](/help/optimizer/setup/semantic-search.md)を有効にし、正確なテキストではなく意味を理解することで、類似の用語と自然言語に一致させます。 セマンティック検索により、いくつかの一般的な類義語の必要性を減らすことができます。 ただし、ブランド固有の用語や技術用語の類義語が必要な場合もあります。 類義語とセマンティック検索を一緒に使用できます。
