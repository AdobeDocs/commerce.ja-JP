# Adobe Commerceのプラットフォームとサービスについて詳しく見る

包括的なコマース基盤が必要な場合や、ホスティングや運用方法を選択する場合、既存のコマース基盤と並行してストアフロントやカタログ機能を望む場合など、Adobe Commerceのニーズに合わせたオプションが用意されています。 Adobe Commerceは、AIを活用した商品検索、超高速のストアフロント、シングルクリックチェックアウトにより、人間主導のショッピングジャーニーとエージェント型のショッピングジャーニーをまたいで、コンバージョンと平均注文額の向上を支援します。 この概要では、主要なサービスと製品を比較し、それらを拡張するサービスと開発者ツールを紹介します。これは、出発点を特定し、自社の導入に適合する機能を検証するのに役立ちます。

各サービスで利用できるサービスは異なります。 実装を計画する際は、特定の製品とデプロイメントモデルに関するドキュメントを確認してください。

## Commerce製品

### B2C/B2B コマース

Adobe Commerceは、単一のCommerceインスタンスの両方のモデルを含め、B2CとB2Bの両方のビジネスモデルをサポートしています。 [Adobe Commerce B2Bの概要](https://experienceleague.adobe.com/en/docs/commerce-admin/b2b/introduction)

B2B能力はサービスによって異なります。 Adobe Commerce クラウドインフラストラクチャおよびオンプレミスの場合、Adobe Commerce B2Bは別途ライセンスとインストールが必要な拡張機能です。 Adobe Commerce as a Cloud Serviceには、企業管理やデフォルトでの見積もりなど、B2Bの主要機能が搭載されています。 [Adobe Commerce B2B](https://experienceleague.adobe.com/en/docs/commerce-admin/start/resources/extensions)を参照してください。

### Adobe Commerce as a Cloud Service

Adobe Commerce as a Cloud Serviceは、フルマネージド型のクラウドネイティブなSaaS （Software as a Service）製品です。 Adobeは、Commerceの主要なアプリケーション、インフラストラクチャ、アップデートを管理します。 コンポーネントには、Commerce基盤、Edge Delivery Servicesを活用したCommerce Storefront、マーチャンダイジングサービス、製品ビジュアル、開発ツールなどがあります。

[Adobe Commerce as a Cloud Serviceの概要](https://experienceleague.adobe.com/en/docs/commerce/cloud-service/overview)を参照してください。

### Adobe Commerce Optimizer

Adobe Commerce Optimizerは、ストアフロント、カタログ、商品の検索、マーチャンダイジング体験を向上させるためのSaaS ソリューションです。 既存のAdobe Commerceやサードパーティのコマース基盤をバックエンドとして使用できるため、取引を管理するシステムを置き換えることなく、顧客体験を近代化できます。

Adobe Commerce Optimizerは、サードパーティソースからカタログデータを取り込むことができます。 サードパーティシステムとのカートおよびチェックアウトの統合には、API MeshやApp Builderなどの統合ツールを使用します。

[Adobe Commerce Optimizerとは何ですか？](https://experienceleague.adobe.com/en/docs/commerce/optimizer/overview)を参照してください。

>[!NOTE]
>
>Adobe Commerce as a Cloud ServiceとAdobe Commerce Optimizerは現在、相互に統合されていません。 実装を計画する際に、それらを個別のアーキテクチャオプションとして扱います。

### Adobe Commerce オンプレミス

Adobe Commerce オンプレミスは、マーチャントまたはそのホスティングプロバイダーによってホストされます。 マーチャントまたはプロバイダーが、ホスティング環境、インフラストラクチャ、プラットフォームサービスを管理します。

[&#x200B; オンプレミス インストールの概要](https://experienceleague.adobe.com/en/docs/commerce-operations/installation-guide/overview)を参照してください。

### Adobe Commerce on cloud infrastructure

Adobe Commerce on cloud infrastructureは、PaaS （Platform as a Service）デプロイメントです。 Adobeがホストされるプラットフォームを管理する一方で、マーチャントはアプリケーションレベルのメンテナンス、カスタムコード、設定、その他の責任分担のタスクに対する責任を負います。

[Commerce on Cloud Infrastructure](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/overview)および[Adobe Commerce as a Cloud Serviceへの移行](https://experienceleague.adobe.com/en/docs/commerce/cloud-service/migration/overview)を参照してください。

## Commerceを拡張するサービス

### ストアフロントおよびマーチャンダイジングサービス

ストアフロントおよび商品体験のためのAdobe Commerceサービスには、次のようなものがあります。

- **[Edge Delivery Servicesを活用したCommerce ストアフロント &#x200B;](https://experienceleague.adobe.com/en/tools/commerce-storefront/merchants/quick-start/create-content/)** – 顧客向けのコマースエクスペリエンスを構築するためのストアフロントオプション。
- **[ストアフロントサービス](/help/landing/home.md)**-[!DNL Adobe Commerce on cloud infrastructure]および[!DNL Adobe Commerce as a Cloud Service]を含む、Adobe Commerce向けのクラウド配信SaaS機能により、最適化されたカタログアクセス、AIを活用した検索と商品レコメンデーション、決済処理を実現して、ストアフロント APIとサービスを強化し、マーチャントがショッピング体験、パフォーマンス、コンバージョンを改善できるよう支援します
  - カタログサービス：最適化された製品カタログ体験とストアフロントのパフォーマンスをサポート
  - ライブサーチ - AIを利用した商品検索を提供します。
  - 商品レコメンデーション：買い物客の行動、傾向、商品の類似性にもとづいてレコメンデーションを提供します。
- **[Commerce Optimizer マーチャンダイジングサービス](/help/optimizer/overview.md)**- Commerce on CloudおよびAdobe Commerce as a Cloud Service向けのクラウド配信のAPI ファースト機能で、カタログデータとAIを活用して商品の見つけやすさを向上させ、最適化されたカタログアクセス、関連検索結果、パーソナライズされた商品レコメンデーションを通じて、買い物客の商品検索を支援し、ストアフロントのパフォーマンスとコンバージョンの向上をサポートします。
  - **商品ビジュアル** - Adobe Experience Manager Assetsとの統合により、商品イメージとメディアをサポートします。

### 支払い

**決済サービス**&#x200B;は、決済方法と、決済処理、注文、請求書の表示を提供します。 ご利用いただけるかどうかは、Commerceの製品とデプロイメントによって異なります。

[決済サービス &#x200B;](https://experienceleague.adobe.com/en/docs/commerce/payment-services/guide-overview)を参照してください。

### データおよび統合サービス

Commerceには、プラットフォームを接続し、データを同期するためのサービスとツールが含まれています。

- **[Commerce Services Connector](/help/landing/saas.md)**：クラウド、オンプレミス、またはMagento Open Source上のAdobe Commerceを、サポート対象のCommerce SaaS サービスに接続します。
- **[SaaS データ書き出し](/help/data-export/overview.md)** – 接続されたサービスに対するCommerce データの移動と同期をサポートします。
- **[Data Connection](/help/data-connection/overview.md)**:Commerce データをAdobe Experience Platformに接続します。
- **[Adobe Commerce Optimizer コネクタ](/help/aco-connector/overview.md)** - サポートされているAdobe CommerceのデプロイメントからAdobe Commerce Optimizerにカタログと価格データを同期します。
- **[プラットフォーム固有のコネクタ](/help/optimizer/integrations/integrations-overview.md#commerce-salesforce-connector)**：サポートされている特定のサードパーティコマースプラットフォームでAdobe Commerce Optimizerを接続します。

### 開発者用ツールと拡張性

開発者の機能には、**Adobe Developer App Builder**、**API Mesh**、**Events**、**Webhook**、および&#x200B;**管理UI SDK**&#x200B;が含まれます。 これらのツールは、カスタムアプリケーション、統合、拡張機能をサポートしています。 ご利用いただけるかどうかは、Commerceの製品によって異なります。

[Adobe Commerce開発者ドキュメント &#x200B;](https://developer.adobe.com/commerce/docs/)を参照してください。
