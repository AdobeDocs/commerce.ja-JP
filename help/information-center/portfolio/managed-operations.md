# 管理操作を持つ[!DNL Adobe Commerce as a Cloud Service]

**より速く起動し、自信を持って実行できます。**

[!DNL Adobe Commerce as a Cloud Service]は、完全に管理されたバージョンのないSaaS プラットフォームです。 Adobeを利用すれば、主要なアプリケーションとインフラストラクチャをホスト、拡張、保護、更新できるため、優れたショッピング体験の構築に集中できます。

管理運用付き&#x200B;**[!DNL Adobe Commerce as a Cloud Service]**&#x200B;は、専用のAdobe Managed Services チームと指定されたカスタマーサクセスエンジニア （CSE）を組み合わせたプレミアム製品です。 オンボーディングからローンチ、継続的な運用に至るまで、[!DNL App Builder]のアプリケーション、統合、[!DNL Edge Delivery Services]によって強化された[!DNL Commerce Storefront]を含む、包括的なコマースソリューションを監視、ガイド、最適化します。

## カスタマーサクセスエンジニア

名前付きCSEは、Adobeの単一の連絡窓口であり、[!DNL App Builder]、[!DNL API Mesh]、[!DNL Commerce Storefront]を含む[!DNL Adobe Commerce as a Cloud Service] ツールセット全体のエキスパートです。[!DNL Edge Delivery Services]が提供します。 CSEは、企業や実装パートナーと連携して、次のことを実行します。

- 申し込み手続きを支援します
- プロビジョニングとプラットフォーム設定の管理
- [!DNL App Builder]個のアプリケーションと[!DNL Edge Delivery Services]による[!DNL Commerce Storefront]を含む、統合とカスタマイズのためのアーキテクチャの原則に関するアドバイス
- [!DNL Adobe Commerce as a Cloud Service]の更新プロセスをサポート
- イベントの計画、実行、モニタリングを通じてイベントをサポートします
- マイルストーンチェックリストと専用のゴーライブ戦争部屋でゴーライブを調整します
- 設定に固有のRunbookを作成して管理します
- 定期的に健康状態と最適化を評価し、推奨事項を提示します

>[!NOTE]
>
>CSEは、ガイダンスとアドバイザリーサービスを提供します。 お客様（または実装パートナー）は、カスタマイズの開発と保守に引き続き責任を負います。 [共有責任セキュリティと運用モデル ](/help/cloud-service/security/shared-responsibility.md)を参照してください。

## プロアクティブなモニタリングとインシデント対応

Managed Servicesチームは、Adobe Commerceの包括的なソリューションを昼夜を問わず監視するため、買い物客に影響を与える前に課題を解決することができます。

- **パフォーマンス監視** - ページの読み込み時間、応答時間、可用性を継続的に追跡します。
- **トラフィックモニタリング** - トラフィックパターンを分析して、問題、脅威、または容量のニーズを示す可能性のあるスパイクまたは異常な動作を検出します。
- **自動アラート** - CSEからのプロアクティブなアウトリーチを使用して、パフォーマンスの低下、ダウンタイム、またはセキュリティイベントに関するアラートを送信します。
- **応答の強化** – 優先度の高いインシデントの間に定期的に更新し、適格なインシデントの根本原因を分析することで、最初の応答と解決までの時間を短縮します。

## セキュリティ

[!DNL Adobe Commerce as a Cloud Service]は、プラットフォーム、インフラストラクチャ、およびコアアプリケーションを保護します。 Managed Operationsでは、次の機能も利用できます。

- **事前対応のセキュリティ ガイダンス**：プロセス外のカスタマイズを安全でコンプライアンスに準拠させるためのエキスパート ガイダンス。
- **Web Application Firewall （WAF）の調整とレポート**：標準のグローバルルールセットを超えるトラフィックに合わせてルールを調整し、ブロックされた内容に関する定期的なレポートを作成します。
- **高度なレート制限** – 体積攻撃に対する追加の保護。
- **セキュリティ監査とリスク評価** – 脆弱性を軽減するための計画を定期的に確認します。
- **インシデント対応** - セキュリティインシデントに対する即時のアクションプランを作成して、影響とダウンタイムを最小限に抑えます。
