# Adobe CommerceとAEM Assetsを連携させてアセット管理を実現

AEM Assetsは、Commerce製品に応じて、様々な統合パスを通じてAdobe Commerceに接続できます。

Adobe Commerce on cloud infrastructureの場合は、AEM Assets Integration for Commerceを使用します。 Adobe Commerce as a Cloud ServiceとAdobe Commerce Optimizerの場合は、AEM Assetsを活用した商品ビジュアルを使用します。

>[!NOTE]
>
>このガイドでは、Adobe Commerce on cloud infrastructure、Adobe Commerce as a Cloud Service、Adobe Commerce OptimizerのAEM Assets統合パスについて説明します。 製品やデプロイメントに合わせた方法でアクセスできます。

## Adobe Experience Managerの導入方法

1. 前提条件と設定については、[AEM Assets Integration for Commerce](/help/aem-assets-integration/overview.md) ドキュメントを参照してください。


1. AEM Assetsでアセット管理を有効にするには、_[Commerce向けAEM Assets統合ガイド](/help/aem-assets-integration/overview.md)_&#x200B;のデプロイメントタイプに関する[次の手順](/help/aem-assets-integration/overview.md#next-steps)の手順に従います。
