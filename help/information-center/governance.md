# Commerceインフォメーションセンターのガバナンス

このドキュメントチームの内部参照は`TOC.md`に記載されていないため、Adobe Experience Leagueに公開されません。

## 所有権

Adobe Commerceのドキュメントチームがインフォメーションセンターを所有しています。 これは`Adobe-Enterprise-Docs/commerce.en`で作成され、リポジトリは`metadata.md`で`git-repo`としてリストされます。

クロスプロダクトであるため、単一のプロダクトチームが所有することはありません。 製品固有の修正は、ここで修正する代わりに、所有している製品チームのドキュメントの連絡先にエスカレーションします。

## 情報センターの内容

| ここに属 | 製品リポジトリに属しています |
| --- | --- |
| 複数の製品やサービスに広がるコンテンツ（製品の選択ガイダンス、製品間の導入ジャーニー、アーキテクチャパターン、ホワイトペーパーなど） | ステップバイステップ設定、API/CLI/config リファレンス、トラブルシューティングなどの単体コンテンツ |
| 信頼できる製品ドキュメントにリンクする短いキュレーションページ | |

- このページに商品の詳細が集約されている場合は、そのページを商品ガイドに移動してリンクします。
- 情報センターは、製品ドキュメントを統合または移行することはなく、個々の製品の機能を文書化することもありません。 新しいことを書く前に、既存の信頼できるコンテンツにリンクする。

## 新しいコンテンツの追加

### 既存セクション内の記事

1. セクションに一致するフォルダーにファイルを追加します。
1. このセクションの`TOC.md`にエントリを追加します。

通常のPR レビューを超える承認は必要ありません。

| 目次セクション | フォルダー |
| --- | --- |
| Commerceのプラットフォームとサービスについて詳しく見る | `portfolio/`, `storefronts/`, `aem-assets/`, `apis/` |
| 役割ごとに始める | `get-started/` |
| インサイトとガイダンス | `guidance-and-insights/` |
| デザイン | `architecture-options/` |
| 移行と導入 | `migration-adoption/` |
| Adobe Analyticsの実装ガイド | `implementation-guides/` |

### インサイトとガイダンス記事

1. `whitepaper-template.md`または`security-guidance-template.md`を`guidance-and-insights/templates/`から`guidance-and-insights/`にコピーします。 テンプレートは公開されません。 COMDOX受注チケットを含む完全なオーサリングプロセスについては、[readme.md](guidance-and-insights/readme.md)を参照してください。
1. テンプレートのプレースホルダーコメントを削除します。
1. コンテンツを公開する準備ができたら、インサイトとガイダンスの下に`TOC.md` エントリを追加します。

### トップレベルセクション

`TOC.md`の新しいトップレベルグループは、ガイドのナビゲーションを変更するので、AI レビューが必要です。 Commerce AIのレビューについては、担当者にお問い合わせください。 パートナーまたはイネーブルメントコンテンツの「役割で始める」など、既存のセクションを最初に再利用します。

### 公開済みURL

URLは、ガイド ID、`TOC.md`のセクション ID （`{#insights-and-guidance}`など）、およびファイル名から作成されます。 フォルダー名はURLに表示されません。 各セクションに一意のIDを付与し、2つの記事が同じURLに解決されないようにします。

## レビュー頻度

- **イベント駆動型** - Commerce製品の名前が変更された場合、リリースされた場合、非推奨になった場合、または可用性が変更された場合は、「Commerce プラットフォームとサービスの概要」、「役割ごとの基本を学ぶ」、「移行と導入」、「実装ガイド」の各セクションを確認します。 例えば、Adobe Commerce as a Cloud ServiceとAdobe Commerce Optimizerが統合されているかどうかを確認します。 最初に古くなったページもあります。
- **スケジュール済み** – 古い用語、ブランディング、または技術的な不正確さを検出するには、6か月ごとに自動コンテンツ監査とレビューを実行します。

## ヘルプ/ランディングとの関係

`help/landing/` （「Adobe Commerce Services Guides」）は、インフォメーション センターの一部ではない別のガイドです。 カタログサービス、ライブサーチ、商品レコメンデーション、決済サービスなどのCommerceサービスに重点を置き、詳細についてはインフォメーションセンターのリンクを参照してください。 この2つを再コープまたは統合することは、このガイドでは解決できないフォローアップの決定です。
